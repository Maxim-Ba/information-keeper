# Information-keeper 🔐

Go pet project для безопасного хранения и синхронизации приватных данных.

## Описание

Система для безопасного хранения и синхронизации приватных данных (пароли, текстовые заметки, банковские карты, файлы) между несколькими устройствами. Реализована на Go с использованием gRPC, PostgreSQL и S3-совместимого хранилища.

## Архитектура и технологии

### Серверная часть
- **gRPC** - основной протокол взаимодействия
- **PostgreSQL** - хранение метаданных и пользовательской информации
- **S3-совместимое хранилище** (MinIO) - хранение бинарных данных
- **JWT** - аутентификация и авторизация
- **Graceful shutdown** - корректное завершение работы

### Клиентская часть
- **gRPC** - взаимодействие с сервером
- **TUI (Terminal User Interface)** - интерфейс на основе [bubbletea](https://github.com/charmbracelet/bubbletea)
- **Синхронизация в реальном времени** - через gRPC streams

## Быстрый старт

### Предварительные требования

- Go 1.21+
- PostgreSQL 13+
- MinIO или совместимое S3 хранилище

### Настройка сервера

1. Клонируйте репозиторий:
```bash
git clone <repository-url>
cd information-keeper
```
2. Настройте переменные окружения:
```bash
export SERVER_PORT=55441
export SERVER_HOST=localhost
export DB_CONNECTION_STRING="postgres://user:pass@localhost:5432/dbname"
export S3_ENDPOINT="http://localhost:9000"
export S3_ACCESS_KEY=minioadmin
export S3_SECRET_KEY=minioadmin
export S3_BUCKET=artifacts
export JWT_SECRET=your-jwt-secret-change-in-production
export PASSWORD_SECRET=your-password-secret-change-in-production
```
3. Запустите сервер:
```go
go run cmd/server/main.go
```

### Настройка клиента
2. Настройте подключение к серверу:
```bash
export SERVER_HOST=localhost
export SERVER_PORT=55441
```
3. Запустите клиент:
```go
go run cmd/client/main.go
```
### Использование
1. Регистрация и вход
- Запустите клиент и выполните регистрацию нового аккаунта
- Используйте Ctrl+T для переключения между входом и регистрацией

2.Управление артефактами
- Просмотр - список всех артефактов с фильтрацией по типам
- Создание - поддержка всех типов данных с валидацией
- Редактирование - изменение метаданных и содержимого
- Удаление - безопасное удаление с подтверждением

3. Синхронизация
- Автоматическая синхронизация при подключении
- Real-time обновления между клиентами
- История изменений
